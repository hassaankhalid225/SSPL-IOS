```
┌─────────────────────────────────────────────────────────────────────────┐
│                         ADMIN CREATES SESSION                            │
└─────────────────────────────────────────────────────────────────────────┘
                                    │
                                    ▼
┌─────────────────────────────────────────────────────────────────────────┐
│                         BACKEND SERVER                                   │
│  ┌──────────────────────────────────────────────────────────────┐      │
│  │  POST /api/scenarios/:id/sessions                             │      │
│  │  - Creates new session                                        │      │
│  │  - Generates join code                                        │      │
│  │  - Triggers notifications                                     │      │
│  └──────────────────────────────────────────────────────────────┘      │
└─────────────────────────────────────────────────────────────────────────┘
                                    │
                    ┌───────────────┴───────────────┐
                    ▼                               ▼
    ┌───────────────────────────┐   ┌───────────────────────────┐
    │   FIREBASE CLOUD          │   │   PUSHER                  │
    │   MESSAGING (FCM)         │   │   (Real-time Events)      │
    │                           │   │                           │
    │   Sends push notification │   │   Broadcasts session      │
    │   to user's device        │   │   events to connected     │
    │                           │   │   clients                 │
    └───────────────────────────┘   └───────────────────────────┘
                    │
                    ▼
┌─────────────────────────────────────────────────────────────────────────┐
│                         MOBILE DEVICE                                    │
│  ┌──────────────────────────────────────────────────────────────┐      │
│  │  MyFirebaseMessagingService                                   │      │
│  │  - Receives FCM notification                                  │      │
│  │  - Extracts data payload                                      │      │
│  │  - Shows Android notification                                 │      │
│  └──────────────────────────────────────────────────────────────┘      │
└─────────────────────────────────────────────────────────────────────────┘
                                    │
                                    ▼
                        ┌───────────────────────┐
                        │  USER TAPS            │
                        │  NOTIFICATION         │
                        └───────────────────────┘
                                    │
                                    ▼
┌─────────────────────────────────────────────────────────────────────────┐
│                         SESSION ACTIVITY                                 │
│  ┌──────────────────────────────────────────────────────────────┐      │
│  │  onCreate()                                                    │      │
│  │  1. Extract join_code from intent                            │      │
│  │  2. Setup WebView                                            │      │
│  │  3. Call autoJoinSession()                                   │      │
│  └──────────────────────────────────────────────────────────────┘      │
└─────────────────────────────────────────────────────────────────────────┘
                                    │
                                    ▼
┌─────────────────────────────────────────────────────────────────────────┐
│                         USE CASE LAYER                                   │
│  ┌──────────────────────────────────────────────────────────────┐      │
│  │  AutoJoinSessionUseCase                                       │      │
│  │  - Emits Loading state                                        │      │
│  │  - Calls repository                                           │      │
│  │  - Handles errors                                             │      │
│  │  - Emits Success/Failure                                      │      │
│  └──────────────────────────────────────────────────────────────┘      │
└─────────────────────────────────────────────────────────────────────────┘
                                    │
                                    ▼
┌─────────────────────────────────────────────────────────────────────────┐
│                         REPOSITORY LAYER                                 │
│  ┌──────────────────────────────────────────────────────────────┐      │
│  │  ScenarioRepository.autoJoinSession()                         │      │
│  │  - Creates HTTP POST request                                 │      │
│  │  - Adds auth token from HttpClient                           │      │
│  │  - Sends to auto-join endpoint                               │      │
│  └──────────────────────────────────────────────────────────────┘      │
└─────────────────────────────────────────────────────────────────────────┘
                                    │
                                    ▼
┌─────────────────────────────────────────────────────────────────────────┐
│                         NETWORK LAYER (KTOR)                             │
│  ┌──────────────────────────────────────────────────────────────┐      │
│  │  POST /api/sessions/:joinCode/auto-join                       │      │
│  │  Headers:                                                     │      │
│  │    Authorization: Bearer <JWT_TOKEN>                          │      │
│  │    Content-Type: application/json                             │      │
│  │                                                               │      │
│  │  Body: (empty - user info from token)                        │      │
│  └──────────────────────────────────────────────────────────────┘      │
└─────────────────────────────────────────────────────────────────────────┘
                                    │
                                    ▼
┌─────────────────────────────────────────────────────────────────────────┐
│                         BACKEND SERVER                                   │
│  ┌──────────────────────────────────────────────────────────────┐      │
│  │  Auto-Join Endpoint Handler                                   │      │
│  │  1. Verify JWT token                                         │      │
│  │  2. Extract user info (name, email) from token               │      │
│  │  3. Check if user already joined                             │      │
│  │  4. Create/Return participant record                         │      │
│  │  5. Generate join_url                                        │      │
│  │  6. Return response                                          │      │
│  └──────────────────────────────────────────────────────────────┘      │
└─────────────────────────────────────────────────────────────────────────┘
                                    │
                                    ▼
                        ┌───────────────────────┐
                        │  RESPONSE             │
                        │  {                    │
                        │    id: 456,           │
                        │    session_id: 123,   │
                        │    name: "John Doe",  │
                        │    email: "john@...", │
                        │    joined_at: "...",  │
                        │    join_url: "..."    │
                        │  }                    │
                        └───────────────────────┘
                                    │
                                    ▼
┌─────────────────────────────────────────────────────────────────────────┐
│                         SESSION ACTIVITY                                 │
│  ┌──────────────────────────────────────────────────────────────┐      │
│  │  onSuccess()                                                  │      │
│  │  1. Extract join_url from response                           │      │
│  │  2. Load URL in WebView                                      │      │
│  │  3. Hide progress indicator                                  │      │
│  └──────────────────────────────────────────────────────────────┘      │
│  ┌──────────────────────────────────────────────────────────────┐      │
│  │  WebView                                                      │      │
│  │  - Displays quiz interface                                   │      │
│  │  - JavaScript enabled                                        │      │
│  │  - DOM storage enabled                                       │      │
│  │  - Handles user interactions                                 │      │
│  └──────────────────────────────────────────────────────────────┘      │
└─────────────────────────────────────────────────────────────────────────┘
                                    │
                                    ▼
                        ┌───────────────────────┐
                        │  USER ATTENDS QUIZ    │
                        │  ✅ Answers questions │
                        │  ✅ Real-time sync    │
                        │  ✅ Progress saved    │
                        └───────────────────────┘
```
